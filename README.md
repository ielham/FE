# Dashboard Frontend

Frontend untuk DSS Dashboard (React + Vite + Mantine).

## Setup

```bash
npm install
npm run dev
```

## Struktur

- `src/api` - client API (axios)
- `src/context` - auth & permission context
- `src/features` - halaman (auth, dashboard, users, roles)
- `src/components` - layout
- `src/routes` - routing & protected route
